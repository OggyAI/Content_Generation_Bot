Drop your target-style reference image here as style-anchor.png (see .env STYLE_REFERENCE_IMAGE).

No reference image is included in this repository. The one used during development was
excluded because its provenance/licensing was not established, and shipping an image
whose rights are unclear is not something a public repo should do.

Supply your own. It should be a single image representing the visual style you want the
generated illustrations to match. It is used only to generate character reference sheets;
background scenes fall back to text-to-image so the reference cannot bleed into them.
