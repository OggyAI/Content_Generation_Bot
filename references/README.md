# Reference transcripts

Drop the two analyzed exemplar scripts here as plain-text `.txt` files. The script stage
auto-loads up to two `.txt` files from this folder and injects them as **voice & rhythm
references only** (never copied) — see Master Brief Part 2 and `src/pipeline/04-script.ts`.

Suggested files:
- `reference-a-yakuza.txt`   — romance/melancholy lane (poetic loop ending)
- `reference-b-hacker.txt`   — moral-dilemma/thriller lane (engagement-CTA ending)

These transcripts are third-party copyrighted work. They are used here purely as private
style references for the model and are never reproduced in output. If this folder is empty,
the pipeline still runs — it falls back to the voice rules encoded in the script prompt.
